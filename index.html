Intro

mod_pr4x1s is a custom mod of firmware 1.04 for the Rossum SP-1200. It brings a subset of the features of pfer's mod for the original E-mu SP-1200, SPf1200, to the Rossum SP-1200.

Why a separate mod? The two machines start up differently. The E-mu boots its firmware from a floppy disk or disk image, so there's no stored firmware to corrupt. The Rossum keeps its firmware in internal storage. mod_pr4x1s gets in through the boot path meant for EEPROM updates, and uses it to load only into memory, so the stored firmware is never changed (see Warning). This path caps the file at the size of the original Rossum firmware, so the firmware and the mod are packed into it together, and new features have to fit in the room that's left.

The modification

mod_pr4x1s gives the segment screen both lines of the display, so everything you need while making a beat is in one place. It also adds a count-in, a readout of which output a pad plays on, and undo/redo for your last take. Everything else works as on a stock SP-1200.

In action

S01 50% ♪=120.01/8 01.01

Stopped

The status is blank. After you stop, the position shows where you stopped.

S01 50% ♪=120.01/8 03.02 Play

Playing

The position counts bars and beats as the segment plays.

S01 50% ♪=120.01/8 02.04 Rec

Recording

Press Record/Edit while recording to punch out and in. The status follows: Play while you're punched out, Rec while you're recording.

S01 50% ♪=120.01/8 00.03 Cnt

Count-in

Hold Tap/Repeat and Record/Edit, then press Run/Stop. You get one bar of clicks, with beat 1 accented, at the metronome's volume (even if the metronome is off). The screen counts 00.01 to 00.04, then recording starts at 01.01. Pads you hit during the count-in sound but aren't recorded, except in its last half beat: those land on the downbeat. There's no count-in under external sync.

S01 50% ♪=120.01/8 A3-7*

Which output is this pad on?

Hit a pad and the position briefly shows its bank, pad and output: A3-7 is bank A, pad 3, output 7. A * means Dynamic Allocation (Special 22) is on for that output pair. While stopped, the readout stays until the next hit. While playing or recording, the position comes back at the next beat.

S01 50% ♪=120.01/8 01.01 Undo

Undo and redo

Stopped, hold Record/Edit and press Copy: the segment goes back to how it was before your last take, and the status shows Undo. Press again for Redo. It keeps toggling, so you can compare by ear. Swing and length changes made since the take are undone and redone along with it. If there's nothing to undo, for example after you've recorded on another segment, the SP-1200 beeps and nothing changes.

Warning

mod_pr4x1s is unofficial software that changes how your SP-1200 behaves. It was built to be as safe as we could make it. Please read how it protects your machine, and where its limits are, before you use it.

How it protects your SP-1200

  • It runs from memory only. mod_pr4x1s never writes to the SP-1200's EEPROM or to its installed operating system. Switch the SP-1200 off and the mod is gone. A normal power-on starts Rossum's firmware exactly as before.
  • It uses a special boot method. Holding Sync at power-on makes the SP-1200 load a file from the card into memory and run it. That's the route Rossum's own EEPROM updater takes, but mod_pr4x1s uses it to instead start the modified firmware in memory. It reprograms nothing. The startup code that does this belongs to the SP-1200, and the mod never changes it. A corrupted or bad build can't brick the machine that way: switch off, then power on normally.
  • It checks at every step. This page builds the mod only from an unmodified copy of Rossum's 1.04 firmware, and checks the result against the reference build. The SP-1200 checks the file as it loads it. Then mod_pr4x1s checks the firmware it has unpacked before running it. If anything doesn't match, it stops with a diagnostic screen instead of running.

But things can still go wrong

  • It's unofficial. mod_pr4x1s isn't made, endorsed or supported by Rossum Electro-Music. If something seems wrong, switch off and check whether it also happens after a normal power-on.
  • Not everything has been tested.
  • Back up your work. Save your sequences and sounds to a card before you use the mod, and keep copies.
  • Follow the instructions. If ReprogramEEPROM? YES/NO ever appears, press No. Don't use Special 28 (UpdateSftware) while the mod is running.

You use mod_pr4x1s at your own risk. It's provided as is, without warranty of any kind, and you're responsible for your own equipment.

Installation

mod_pr4x1s is built from Rossum's own firmware, which you download from Rossum. This page builds the mod from it on your computer.

  1. Download Rossum's Main FW 1.04: SP1200fw_1_04_240507.zip. If that link doesn't work, get it from Rossum's downloads page (Main FW 1.04). There's no need to unzip it.
  2. Drop the zip below, or the sp1200fw.bin inside it. The page checks that it's an unmodified copy of 1.04 and builds sp1200eefw.bin.
  3. Download the zip and unzip it. Copy only sp1200eefw.bin to the top level of your SP-1200's SD card: not the README, and not the zip. Keep that file name. If the card already has a file with that name, replace it. Eject the card before you take it out.

Usage

mod_pr4x1s runs from memory only. Load it from the card each time you want it. A normal power-on starts the original Rossum firmware.

  1. Turn off your Rossum SP-1200.
  2. Put the card in your SP-1200. Hold Sync and switch the SP-1200 on.
  3. At Update EEPROM software? [Y/N], press Yes. Despite the wording, mod_pr4x1s doesn't write to the EEPROM.
  4. At Insert Card with SW, press Enter.
  5. The screen shows mod_pr4x1s / Loading OS... briefly, then the SP-1200 starts as usual. Setup 23 shows Main FW 1.04+pxs while the mod is running.

The mod stays loaded until you switch the SP-1200 off.

If something goes wrong

⚠ ReprogramEEPROM? YES/NO
Press No. That's Rossum's real EEPROM updater: the card has Rossum's sp1200eefw.bin, not the one built here.
Fail!Retry?[Y/N]
The SP-1200 couldn't read the file. Press Yes to try again. If it keeps failing, copy the file to the card again and check its MD5 matches the one shown above.
Two lines of letters and numbers, then nothing
The file was damaged on its way into the SP-1200, and mod_pr4x1s stopped instead of running it. Switch off, copy the file to the card again and retry.

While mod_pr4x1s is running, don't use Special 28 (UpdateSftware). Switch the SP-1200 off and on normally first.
